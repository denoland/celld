Chat Commands

Regular text will be sent as a chat message to everyone.

You can also use these JSON commands:

  • {"type":"nickname","username":"YourNewName"} - Change your nickname
  • {"type":"private","to":"Username","content":"Secret message"} - Send a private message
  • {"type":"typing","isTyping":true} - Show you are typing (set to false when done)
